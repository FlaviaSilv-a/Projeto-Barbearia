# Barbearia Carioca - Site (HTML/CSS/JS)

Arquivos prontos para subir no GitHub Pages.

## Estrutura
- `index.html` - página principal (home)
- `styles.css` - estilos
- `script.js` - comportamento (botão WhatsApp)
- `logo.svg` - logo em vetor (pode alterar)

## Como usar
1. Edite `script.js` e substitua a constante `WHATSAPP_NUMBER` pelo número do cliente no formato internacional (apenas dígitos). Ex.: `5511999998888`.
2. Opcional: personalize textos, endereço e horários em `index.html`.
3. Faça o upload para o GitHub (repositório público) e ative o GitHub Pages (branch `main`).

## Observações
- O design é intencionalmente simples e responsivo. As cores e logo buscam evocar o clima carioca (mar + sol).
- Se quiser eu já posso gerar variações de cor, versões em inglês ou versões com favicon.
